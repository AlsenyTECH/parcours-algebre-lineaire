# Parcours Algèbre linéaire

Parcours pas à pas sur les **matrices** et les **espaces vectoriels** (prépa ECG 1) :
explications, vidéos, exercices corrigés et évaluations chronométrées.

Site : https://alsenytech.github.io/parcours-algebre-lineaire/

- `index.html` : la page du parcours (22 étapes)
- `videos/` : les 13 vidéos tutos
- `assets/` : MathJax et les polices, pour que le site fonctionne aussi sans connexion

## Contenu

- **Partie A, matrices** (9 étapes) : vocabulaire, produit, matrices E(i,j), inverse, puissances, systèmes homogènes.
- **Partie B, espaces vectoriels** (10 étapes) : sous-espaces, Vect, intersection et réunion, familles génératrices, familles libres, bases, dimension.
- **Pour finir** (3 étapes) : attentes du correcteur et deux évaluations chronométrées.

## Utilisation hors ligne

Télécharger le dépôt (ou le zip), puis ouvrir `index.html` dans un navigateur. Aucune connexion n'est nécessaire.
